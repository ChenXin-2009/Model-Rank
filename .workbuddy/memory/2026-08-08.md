## 散点图（IndexCostScatter）移动端双指缩放失效问题分析（未改动）

- 用户反馈：手机双指缩放散点图时表现为"拖动"而非缩放，要求先分析、不动代码。
- 组件：`src/components/IndexCostScatter.tsx`（SVG 散点图，Pointer Events 实现捏合/拖动）。
- 定位到的根因（按可能性排序）：
  1. `onPointerLeave={onPointerUp}`（第 441 行）——移动端手指滑出 SVG 边界即触发 `onPointerUp`，会执行 `pointersRef.delete` 并清掉 `pinchRef`，双指捏合中途被破坏，退化为单指拖动逻辑。
  2. `setPointerCapture` 只对第一根手指且捕获目标是 `e.target`（可能是 `<a>`/`<image>`/`<text>` 子元素）而非 SVG 根（第 303 行），第二根手指 down 时直接 return 没有捕获；iOS Safari 对子元素 pointer capture + 多点触控兼容性差，第二根手指 down/事件易丢失。
  3. `touch-action: none` 加在 `.scatter-svg`（SVG 元素）上（globals.css 第 283 行），iOS Safari 对 SVG 元素的 touch-action 支持不完整，浏览器可能拦截双指手势触发 pointercancel。
  4. pinch 状态机脆弱：任一指针 leave/cancel 后 `pinchRef` 置 null 且不重建，剩余手指要么走 drag（表现为拖动）要么卡住。
- 修复方向（待用户确认后执行）：移除/条件化 onPointerLeave；统一 `svgRef.current.setPointerCapture`；pinch 降级时重建 drag 起点；touch-action 加到外层容器。
